<table>

<td width="50%">

### 🎯 The Problem

Traditional banking queues can involve:

- Long physical waiting times
- Unclear queue positions
- Manual queue management
- Limited visibility for customers
- Inefficient staff workflows

</td>

<td width="50%">

### 💡 The Solution

A digital token-based queue system where customers can:

- Select banking services
- Generate digital tokens
- Track queue position
- Monitor ticket status
- Receive estimated waiting information

</td>
</tr>
</table>

### 👥 User Workflows

```text
CUSTOMER

Register
   ↓
Login
   ↓
Select Banking Service
   ↓
Generate Token
   ↓
Track Queue Position
   ↓
Wait for Service
   ↓
Ticket Completed
